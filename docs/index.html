About the Project

This project is focused on building a lightweight narrative game engine designed to simplify interactive storytelling. Developers and writers can drive dialogue, scene transitions, and narrative choices using simple, text-based scripts.

Key Features

  • Simple Scripting: Write dialogue and control scene flow using readable text files.
  • Automated Systems: Built-in support for game state saving and loading.
  • Player Controls: Integrated fast-forwarding and dialogue history controls.
  • Menu Management: Built-in UI systems for menus and player options.

Current Status & Next Steps

The project is currently under active initial development. Our immediate focus includes:

  • Designing the core application layout and rendering structure.
  • Implementing state management and core game logic.
