Recent Changes: Collision Detection

Log: Added collision detection for specific tiles so that it can be blocked.

This update introduces tile-based blocking to restrict player and entity movement across the map. Key components affected by this change include:

  • Entity Updates: Core entities now track their solid areas and collision states via Entity.class.
  • Collision Logic: The newly implemented CollisionChecker.class calculates boundaries and prevents movement through restricted spaces.
  • Tile Management: Individual map tiles now have a boolean collision property managed within Tile.class to determine if they are passable or solid.
